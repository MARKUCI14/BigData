# ADR-005: Use Streamlit for serving and visualization

- **Status:** Proposed
- **Date:** 2026-11-23

## Context

The accepted proposal and diagram specify a dashboard for historical analysis and recent stream summaries.

## Decision

Use Streamlit as the proposed Python visualization interface.

## Consequences

- Document dashboard launch/configuration and the query interface to lake and serving data after they exist.
- Visualizations must label time/geography, sources and coverage, units, and the distinction between reported observations and population size.
